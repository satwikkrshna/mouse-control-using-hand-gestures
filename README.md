# Live Mouse Control Using Hand Gestures

## Quick Start
1. Install deps: `pip install -r requirements.txt`
2. Run: `python opencv_gesture_mouse.py` or `python working_opencv_gesture_mouse.py`

## Gestures
- Hand palm: Mouse move
- 1 finger: Left click
- 2 fingers: Right click
- Fist: Screenshot

Press 'q' to quit.

## VSCode Run Fix
- Install Python extension.
- Ctrl+Shift+P > Tasks: Run Task > Run Gesture Mouse.
- Or terminal run.

Enjoy!
